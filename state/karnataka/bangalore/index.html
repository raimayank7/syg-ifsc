Questions

How do I find the IFSC code of a bank branch in Bangalore?

Choose the bank on this page, then find the branch by its name or address. Bangalore has 1,003 branches of 47 banks in our list. For example, Axis Bank, Corporate Banking Branch is UTIB0001541; Axis Bank, J C Road is UTIB0001688; Axis Bank, Rajarajeshwari Nagar is UTIB0001770.

Which banks have the most branches in Bangalore?

Axis Bank (153), State Bank of India (99), Indusind Bank (68), HDFC Bank (62), Karnataka Bank (59), Indian Bank (58).

Is the IFSC code the same for all branches in Bangalore?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
