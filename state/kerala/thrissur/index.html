Questions

How do I find the IFSC code of a bank branch in Thrissur?

Choose the bank on this page, then find the branch by its name or address. Thrissur has 720 branches of 39 banks in our list. For example, Catholic Syrian Bank, Amballur is CSBK0000003; Catholic Syrian Bank, Annamanada is CSBK0000004; Catholic Syrian Bank, Ashtamichira is CSBK0000005.

Which banks have the most branches in Thrissur?

Catholic Syrian Bank (138), Federal Bank (63), Kerala State Co-operative Bank (59), Canara Bank (59), State Bank of India (56), Kerala Gramin Bank (48).

Is the IFSC code the same for all branches in Thrissur?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
