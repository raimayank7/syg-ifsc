Questions

How do I find the IFSC code of a bank branch in Kannur?

Choose the bank on this page, then find the branch by its name or address. Kannur has 422 branches of 32 banks in our list. For example, Kerala Gramin Bank, TB Cell is KLGB0040342; Kerala Gramin Bank, Kannur RO is KLGB0040394; Kerala Gramin Bank, Thalassery RO is KLGB0040398.

Which banks have the most branches in Kannur?

Kerala Gramin Bank (99), Kerala State Co-operative Bank (66), IDBI (53), State Bank of India (41), Federal Bank (29), Esaf Small Finance Bank (19).

Is the IFSC code the same for all branches in Kannur?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
