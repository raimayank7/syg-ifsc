Which banks have the most branches in Kottayam?

State Bank of India (144), South Indian Bank (58), Kerala State Co-operative Bank (58), Federal Bank (55), Canara Bank (52), Kerala Gramin Bank (38).

Is the IFSC code the same for all branches in Kottayam?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
