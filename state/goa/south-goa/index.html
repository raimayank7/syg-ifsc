How do I find the IFSC code of a bank branch in South Goa?

Which banks have the most branches in South Goa?

Canara Bank (34), Union Bank of India (32), HDFC Bank (31), State Bank of India (31), Bank of Baroda (21), Goa State Co-operative Bank (21).

Is the IFSC code the same for all branches in South Goa?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
