Which banks have the most branches in Bilaspur?

State Bank of India (49), Chhattisgarh Rajya Gramin Bank (43), HDFC Bank (28), Punjab National Bank (20), Canara Bank (15), ICICI Bank (14).

Is the IFSC code the same for all branches in Bilaspur?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
