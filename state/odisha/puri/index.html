How do I find the IFSC code of a bank branch in Puri?

Which banks have the most branches in Puri?

Indian Overseas Bank (54), State Bank of India (36), Canara Bank (19), Bank of Baroda (13), Union Bank of India (12), UCO Bank (12).

Is the IFSC code the same for all branches in Puri?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
