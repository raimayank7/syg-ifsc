Questions

How do I find the IFSC code of a bank branch in Solan?

Choose the bank on this page, then find the branch by its name or address. Solan has 201 branches of 29 banks in our list. For example, State Bank of India, Subathu is SBIN0002466; State Bank of India, Solan is SBIN0006401; State Bank of India, Parwanoo is SBIN0006403.

Which banks have the most branches in Solan?

State Bank of India (47), UCO Bank (27), Punjab National Bank (24), HDFC Bank (15), Axis Bank (8), ICICI Bank (8).

Is the IFSC code the same for all branches in Solan?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
