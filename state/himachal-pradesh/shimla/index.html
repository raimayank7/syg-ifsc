Which banks have the most branches in Shimla?

Himachal Pradesh State Co-operative Bank (73), State Bank of India (52), Punjab National Bank (31), UCO Bank (12), HDFC Bank (11), Axis Bank (7).

Is the IFSC code the same for all branches in Shimla?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
