Questions

How do I find the IFSC code of a bank branch in Kangra?

Choose the bank on this page, then find the branch by its name or address. Kangra has 331 branches of 23 banks in our list. For example, Kangra Central Co-operative Bank, Dharamshala is KACE0000002; Kangra Central Co-operative Bank, Nurpur is KACE0000003; Kangra Central Co-operative Bank, Main Bazar Palampur is KACE0000004.

Which banks have the most branches in Kangra?

Kangra Central Co-operative Bank (109), State Bank of India (67), HDFC Bank (24), Canara Bank (22), Punjab National Bank (18), UCO Bank (17).

Is the IFSC code the same for all branches in Kangra?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
