How do I find the IFSC code of a bank branch in Hooghly?

Which banks have the most branches in Hooghly?

State Bank of India (51), Punjab National Bank (37), Bandhan Bank (26), Axis Bank (19), Union Bank of India (12), Ujjivan Small Finance Bank (10).

Is the IFSC code the same for all branches in Hooghly?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
