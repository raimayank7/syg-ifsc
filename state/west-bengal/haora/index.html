How do I find the IFSC code of a bank branch in Haora?

Choose the bank on this page, then find the branch by its name or address. Haora has 183 branches of 27 banks in our list. For example, UCO Bank, Mahiari is UCBA0000389; UCO Bank, Nibra is UCBA0000398; UCO Bank, Banipur is UCBA0000407.

Which banks have the most branches in Haora?

UCO Bank (30), Indian Bank (22), ICICI Bank (17), HDFC Bank (14), Canara Bank (14), Howrah District Central Co-operative Bank (12).

Is the IFSC code the same for all branches in Haora?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
