Questions

How do I find the IFSC code of a bank branch in Ludhiana?

Choose the bank on this page, then find the branch by its name or address. Ludhiana has 974 branches of 43 banks in our list. For example, State Bank of India, Jagraon is SBIN0000655; State Bank of India, Ludhiana Main is SBIN0000674; State Bank of India, RNW Millerganj is SBIN0000731.

Which banks have the most branches in Ludhiana?

State Bank of India (117), Punjab National Bank (111), HDFC Bank (82), Axis Bank (76), Punjab & Sind Bank (74), ICICI Bank (60).

Is the IFSC code the same for all branches in Ludhiana?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
