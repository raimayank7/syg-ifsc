Which banks have the most branches in Coimbatore?

Canara Bank (150), State Bank of India (142), HDFC Bank (79), Indian Overseas Bank (73), ICICI Bank (71), Union Bank of India (66).

Is the IFSC code the same for all branches in Coimbatore?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
