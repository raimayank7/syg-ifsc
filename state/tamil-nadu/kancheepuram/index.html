Which banks have the most branches in Kancheepuram?

City Union Bank (64), Indian Overseas Bank (55), HDFC Bank (54), Canara Bank (51), ICICI Bank (44), State Bank of India (42).

Is the IFSC code the same for all branches in Kancheepuram?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
