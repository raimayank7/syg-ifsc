Which banks have the most branches in Madurai?

Canara Bank (85), State Bank of India (84), Indian Overseas Bank (58), Indian Bank (42), HDFC Bank (37), Karur Vysya Bank (33).

Is the IFSC code the same for all branches in Madurai?

No. Every branch of every bank has its own code. The first four letters name the bank and the last six name the branch, so two branches in the same town never share a code.
