SWIFT codes of Indian bank branches

A SWIFT code (also called a BIC) is what a bank abroad needs to send money to an account in India. Check a SWIFT code here, or look up the branches that have a code of their own.

11 characters: 4 letters, a zero, then 6 letters or digits. You see the bank, branch, address and MICR code. An old code of a merged or closed bank works too: you see what happened to it. You can also type a SWIFT code of an Indian bank.

How a SWIFT code is built

Take SBININBB476 (State Bank of India, Agartala). SBIN is the bank. IN is the country, India. BB is the location. The last three characters, 476, name the branch. A code with only the first eight characters is the code of the bank's main office. An IFSC code looks different: its fifth character is always the digit zero.

If your branch has no code of its own

That is normal. Most branches in India do not have one. Ask your bank which SWIFT code to give to the sender: it is usually the code of the bank's main or foreign-exchange branch. The sender then adds your name, your account number and your branch, and the bank passes the money on to your account. Small banks that have no SWIFT code at all receive foreign money through a larger partner bank; they tell you that bank's details.

Questions

Do Indian banks have SWIFT codes?

Yes. A bank in India that receives or sends money abroad has a SWIFT code, also called a BIC. It is used for transfers between countries. Transfers inside India use the IFSC code.

Does every branch have its own SWIFT code?

No. Usually only the branches that handle foreign exchange have a code of their own. For any other branch, the money comes through the main or foreign-exchange branch of the same bank, and the sender uses that branch's SWIFT code together with your account number.

My bank or branch is not in this list. Does it have no SWIFT code?

Not necessarily. This list holds only the SWIFT codes that are in the open data set we use: 877 branch codes and the bank codes shown above. A bank that is not here may well have a code. Ask your bank for its SWIFT code and its instructions for receiving money from abroad.

Is a SWIFT code the same as an IFSC code?

No. An IFSC code has 11 characters with a zero in the fifth place and works only inside India. A SWIFT code has 8 or 11 characters, and its fifth and sixth characters are the country, IN for India.

Does India use IBAN numbers?

No. Indian bank accounts have no IBAN. A sender abroad needs your account number and the SWIFT code of your bank, and many banks also ask for the IFSC code of your branch.
