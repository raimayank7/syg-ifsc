Questions

What is the SWIFT code of State Bank of India?

State Bank of India codes begin with SBININ. In our list, 749 of its 26,483 branches have a code of their own; for example Agartala, West Tripura is SBININBB476. For a branch that is not in the list, ask the bank which code to use.

My State Bank of India branch is not in this list. What do I give the sender?

Ask your branch. Banks route money for branches without a SWIFT code through a main or foreign-exchange branch, and they tell you which code to use together with your account number and IFSC code.

Can I use the SWIFT code of another State Bank of India branch?

Only if the bank tells you to. The money is matched to your account by the account number, but a code the bank did not give you can delay the payment or send it back.
