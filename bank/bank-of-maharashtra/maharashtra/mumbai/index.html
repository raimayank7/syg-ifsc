What is the IFSC code of Bank of Maharashtra in Mumbai?

Bank of Maharashtra has 46 branches in Mumbai, and each has its own IFSC code. Asset Recovery Branch Mumbai is MAHB0001450; Bank of Maharashtra Imps is MAHB0003007; Corporate Finance Branch Fort Mumbai is MAHB0002084. Use the code of the branch where the account is held.

Which Bank of Maharashtra branch in Mumbai should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another Bank of Maharashtra branch in Mumbai?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
