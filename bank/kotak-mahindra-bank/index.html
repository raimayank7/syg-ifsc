About Kotak Mahindra Bank IFSC codes

Kotak Mahindra Bank is a private sector bank. It has 2,532 branches with an IFSC code in 29 states and union territories. Its IFSC codes begin with KKBK. An example is KKBK0000131 (Kanpur, Kanpur).

  • Most branches: Maharashtra (571), Gujarat (267), Karnataka (236), Telangana (155), Uttar Pradesh (153).
  • Places with the most branches: Bangalore Urban (96), Delhi (95), Pune (91), Mumbai Suburban (78), Ahmedabad (71), Chennai (64).
  • 2,471 of 2,532 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: all but 1 branch.
  • 2,532 branches are listed as UPI enabled.
  • 144 older codes of this bank are no longer in use: see the old codes.

Questions

What is the IFSC code of Kotak Mahindra Bank?

Every branch of Kotak Mahindra Bank has its own IFSC code. The codes begin with KKBK. For example, the code of Kanpur, Kanpur is KKBK0000131. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Kotak Mahindra Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Kotak Mahindra Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
