Questions

What is the IFSC code of West Bengal State Co-operative Bank in Kolkata?

West Bengal State Co-operative Bank has 15 branches in Kolkata, and each has its own IFSC code. Behala Branch is WBSC0000004; Beliaghata Branch is WBSC0000005; Bhowanipur Branch is WBSC0000002. Use the code of the branch where the account is held.

Which West Bengal State Co-operative Bank branch in Kolkata should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another West Bengal State Co-operative Bank branch in Kolkata?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
