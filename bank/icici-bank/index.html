About ICICI Bank IFSC codes

ICICI Bank is a private sector bank. It has 8,232 branches with an IFSC code in 35 states and union territories. Its IFSC codes begin with ICIC. An example is ICIC0000001 (Chennaicenotaph Road, Chennai).

  • Most branches: Maharashtra (1,112), Tamil Nadu (690), Rajasthan (665), Gujarat (642), Uttar Pradesh (585).
  • Places with the most branches: Delhi (279), Greater Bombay (272), Bangalore Urban (266), Hyderabad (223), Chennai (180), Kolkata (176).
  • 7,618 of 8,232 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: all but 2 branches.
  • 8,232 branches are listed as UPI enabled.
  • 37 older codes of this bank are no longer in use: see the old codes.

Questions

What is the IFSC code of ICICI Bank?

Every branch of ICICI Bank has its own IFSC code. The codes begin with ICIC. For example, the code of Chennaicenotaph Road, Chennai is ICIC0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my ICICI Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one ICICI Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
