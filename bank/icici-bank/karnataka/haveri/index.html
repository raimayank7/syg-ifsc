What is the IFSC code of ICICI Bank in Haveri?

ICICI Bank has 10 branches in Haveri, and each has its own IFSC code. Basapur is ICIC0002900; Byadagi is ICIC0004457; Haveri is ICIC0000522. Use the code of the branch where the account is held.

Which ICICI Bank branch in Haveri should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another ICICI Bank branch in Haveri?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
