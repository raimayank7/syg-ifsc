ICICI Bank: old IFSC codes that are no longer in use

ICICI Bank is working as usual. These 43 codes were in an earlier list of the Reserve Bank and are not in the current one (data as of 1 September 2026). A bank takes a code out when it closes a branch, joins it with a nearby branch or gives a branch a new code. The accounts are not closed: they move to another branch of ICICI Bank, which has its own code.

For 2 of them a current branch has the same name in the same place, and its code is shown. That is a match by name, not a statement from the bank, so confirm it before a payment. For the others, look for the branch in the current list of ICICI Bank or ask the account holder.
