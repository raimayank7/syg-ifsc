Apna Sahakari Bank: old IFSC codes that are no longer in use

Apna Sahakari Bank is working as usual. These 25 codes were in an earlier list of the Reserve Bank and are not in the current one (data as of 1 September 2026). A bank takes a code out when it closes a branch, joins it with a nearby branch or gives a branch a new code. The accounts are not closed: they move to another branch of Apna Sahakari Bank, which has its own code.

For 0 of them a current branch has the same name in the same place, and its code is shown. That is a match by name, not a statement from the bank, so confirm it before a payment. For the others, look for the branch in the current list of Apna Sahakari Bank or ask the account holder.
