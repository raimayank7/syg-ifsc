What is the IFSC code of State Bank of India in Mancherial?

State Bank of India has 4 branches in Mancherial, and each has its own IFSC code. Cac Mancherial is SBIN0062003; Mini Racpc Mancherial is SBIN0064140; Orient Cement Complex, Devapur is SBIN0061346. Use the code of the branch where the account is held.

Which State Bank of India branch in Mancherial should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another State Bank of India branch in Mancherial?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
