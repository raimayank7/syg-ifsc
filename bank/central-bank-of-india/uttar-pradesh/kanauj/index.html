Questions

What is the IFSC code of Central Bank of India in Kanauj?

Central Bank of India has 3 branches in Kanauj, and each has its own IFSC code. District Court,Kannauj is CBIN0284009; Govt. Medical College Tirwaganj,Kannauj is CBIN0284609; Kannauj is CBIN0283150. Use the code of the branch where the account is held.

Which Central Bank of India branch in Kanauj should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another Central Bank of India branch in Kanauj?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
