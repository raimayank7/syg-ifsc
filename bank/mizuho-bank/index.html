About Mizuho Bank IFSC codes

Mizuho Bank is a foreign bank. It has 7 branches with an IFSC code in 5 states and union territories. Its IFSC codes begin with MHCB. An example is MHCB0000001 (Nariman Point, Greater Mumbai).

  • Most branches: Maharashtra (3), Delhi (1), Gujarat (1), Karnataka (1), Tamil Nadu (1).
  • Places with the most branches: Greater Mumbai (2), Mumbai (1), Bangalore Rural (1), Chennai (1), Ahmedabad (1), Delhi (1).
  • 5 of 7 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: all but 1 branch.

Questions

What is the IFSC code of Mizuho Bank?

Every branch of Mizuho Bank has its own IFSC code. The codes begin with MHCB. For example, the code of Nariman Point, Greater Mumbai is MHCB0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Mizuho Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Mizuho Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
