What is the IFSC code of IDBI in East Singhbhum?

IDBI has 12 branches in East Singhbhum, and each has its own IFSC code. Jharkhand State CO OP Bank JHB Baharagora BHG is IBKL063J100; Jharkhand State CO OP Bank JHB Chakulia Cha is IBKL063J103; Jharkhand State CO OP Bank JHB Chandil CHD is IBKL063JS90. Use the code of the branch where the account is held.

Which IDBI branch in East Singhbhum should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another IDBI branch in East Singhbhum?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
