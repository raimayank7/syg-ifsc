Questions

What is the IFSC code of Delhi State Co-operative Bank in North East?

Delhi State Co-operative Bank has 3 branches in North East, and each has its own IFSC code. Bhajanpura is DLSC0000027; Ghonda is DLSC0000041; Wazirabad is DLSC0000032. Use the code of the branch where the account is held.

Which Delhi State Co-operative Bank branch in North East should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another Delhi State Co-operative Bank branch in North East?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
