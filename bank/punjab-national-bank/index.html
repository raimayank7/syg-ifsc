About Punjab National Bank IFSC codes

Punjab National Bank is a public sector bank. It has 13,048 branches with an IFSC code in 35 states and union territories. Its IFSC codes begin with PUNB. An example is PUNB0000010 (RTGS-HO Amalgamated Obc, Mumbai).

  • Most branches: Uttar Pradesh (2,053), West Bengal (1,380), Punjab (1,225), Haryana (896), Rajasthan (892).
  • Places with the most branches: Kolkata (251), Delhi (231), Ludhiana (111), Punjab (103), Jaipur (100), Lucknow (96).
  • 6,904 of 13,048 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: all but 1 branch. RTGS: all but 2 branches.
  • 13,048 branches are listed as UPI enabled.
  • 182 older codes of this bank are no longer in use: see the old codes.
  • 128 branches have a SWIFT code for money from abroad.

Questions

What is the IFSC code of Punjab National Bank?

Every branch of Punjab National Bank has its own IFSC code. The codes begin with PUNB. For example, the code of RTGS-HO Amalgamated Obc, Mumbai is PUNB0000010. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Punjab National Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Punjab National Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
