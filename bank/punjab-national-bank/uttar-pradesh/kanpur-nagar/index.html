Questions

What is the IFSC code of Punjab National Bank in Kanpur Nagar?

Punjab National Bank has 18 branches in Kanpur Nagar, and each has its own IFSC code. Araul Dist. Kanpur is PUNB0187110; Chaubepur Distt Kanpur Nagar is PUNB0178510; Govindnagar is PUNB0100820. Use the code of the branch where the account is held.

Which Punjab National Bank branch in Kanpur Nagar should I choose?

The branch that holds the account you are paying. Its name is printed on the cheque book and passbook and shown in the bank app next to the account number. If you only know the area, compare the addresses in the list on this page.

Can I use the code of another Punjab National Bank branch in Kanpur Nagar?

A payment with the right account number and the code of another branch of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned. Use the exact code.
