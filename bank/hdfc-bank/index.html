About HDFC Bank IFSC codes

HDFC Bank is a private sector bank. It has 10,737 branches with an IFSC code in 36 states and union territories. Its IFSC codes begin with HDFC. An example is HDFC0000001 (Tulsiani Chmbrs - Nariman PT, Greater Mumbai).

  • Most branches: Maharashtra (1,770), Uttar Pradesh (983), Gujarat (756), Tamil Nadu (708), Punjab (635).
  • Places with the most branches: Pune (549), Bangalore Urban (207), Chennai (206), Hyderabad (182), Delhi (177), Kolkata (157).
  • 10,660 of 10,737 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: all but 1 branch.
  • 10,737 branches are listed as UPI enabled.
  • 414 older codes of this bank are no longer in use: see the old codes.
  • SWIFT code for money from abroad: HDFCINBB, one code for the whole bank in our data. About SWIFT codes

HDFC Bank is a private sector bank. A private sector bank is owned mostly by private shareholders, not by the government. It works under the same Reserve Bank of India rules as a public sector bank: the same payment systems, the same deposit insurance and the same complaint system (the RBI Ombudsman).

Its branches are spread over 35 states and union territories; the most are in Maharashtra, Uttar Pradesh and Gujarat. 10,737 of them also have a SWIFT code for money from abroad.

Banks that became part of HDFC Bank: Centurion Bank of Punjab (2008). Their old IFSC codes are listed with the new ones on the pages linked here.

Deposit insurance: HDFC Bank is on the list of insured banks of DICGC, the deposit insurer owned by the Reserve Bank of India. Deposits there are insured up to ₹5 lakh for each depositor, counting savings, current, fixed and recurring deposits in the bank together, principal and interest.

Questions

What is the IFSC code of HDFC Bank?

Every branch of HDFC Bank has its own IFSC code. The codes begin with HDFC. For example, the code of Tulsiani Chmbrs - Nariman PT, Greater Mumbai is HDFC0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my HDFC Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one HDFC Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
