About Tura Urban Co-operative Bank IFSC codes

Tura Urban Co-operative Bank is a urban co-operative bank. It has 1 branch with an IFSC code in 1 state or union territory. Its IFSC codes begin with YESB, the bank code of Yes Bank. Smaller banks often send and receive NEFT and RTGS payments through a larger bank (a sub-member arrangement), and their IFSC codes then carry that bank's four letters. An example is YESB0TURA01 (Tura Urban Co-operative Bank Imps, Mumbai).

  • Most branches: Maharashtra (1).
  • 1 of 1 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: every branch.

Questions

What is the IFSC code of Tura Urban Co-operative Bank?

Every branch of Tura Urban Co-operative Bank has its own IFSC code. The codes begin with YESB. For example, the code of Tura Urban Co-operative Bank Imps, Mumbai is YESB0TURA01. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Tura Urban Co-operative Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Tura Urban Co-operative Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
