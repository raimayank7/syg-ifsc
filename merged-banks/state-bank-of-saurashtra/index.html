State Bank Of Saurashtra IFSC codes: old codes and the new State Bank of India codes

State Bank Of Saurashtra merged into State Bank of India in the year 2008. Every branch became a branch of State Bank of India and got a new IFSC code.

What this page lists

441 old codes of State Bank Of Saurashtra that were in the lists of the Reserve Bank between December 2006 and the merger and are not in use now. For 0 of them we show the new code, found by matching the branch name and place in the current list of State Bank of India. Confirm it with the bank before a payment. Where no single branch matched, the page says so instead of guessing: some branches were closed or joined with a nearby branch after the merger.

Is my money safe?

Yes. In a merger every account, deposit and loan moves to the bank that took over, with the same balance. Only the names and codes change: the IFSC code, usually the MICR code, the cheque book, and sometimes the account number.

What to do if you still have the old code

  1. If you are paying someone: ask them for the new code, or find it here and confirm it with them. A payment to the old code is refused and the money returns to your account.
  2. If it is your own account: use the code printed on your new cheque book or passbook, or shown in the bank's app. Give the new code to your employer, tenants, clients, mutual funds, insurers and the income tax portal, so salaries, refunds and SIP or EMI debits keep working.
  3. Old cheques: cheque books of the merged bank stopped being accepted after a notice period. Ask your branch for a new one.

Check an old code

11 characters: 4 letters, a zero, then 6 letters or digits. You see the bank, branch, address and MICR code. An old code of a merged or closed bank works too: you see what happened to it.

Questions

What is the new IFSC code of my State Bank Of Saurashtra branch?

Find the branch in the list on this page, or type the old code in the checker. Where a new State Bank of India code is known it is shown next to the old one.

Do old State Bank Of Saurashtra IFSC codes still work?

They are no longer in the list of the Reserve Bank, and the branches now have codes of State Bank of India. A payment to an old code is likely to be refused and returned, so use the new code.

Did my account number change after the merger?

In some mergers account numbers stayed the same and in others they changed when the accounts moved to the new bank's computer system. Your passbook, statement or the bank's app shows the number in use now.
