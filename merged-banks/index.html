Is my money safe?

Yes. In a merger every account, deposit and loan moves to the bank that took over, with the same balance. Only the names and codes change: the IFSC code, usually the MICR code, the cheque book, and sometimes the account number.

What to do if you still have the old code

  1. If you are paying someone: ask them for the new code, or find it here and confirm it with them. A payment to the old code is refused and the money returns to your account.
  2. If it is your own account: use the code printed on your new cheque book or passbook, or shown in the bank's app. Give the new code to your employer, tenants, clients, mutual funds, insurers and the income tax portal, so salaries, refunds and SIP or EMI debits keep working.
  3. Old cheques: cheque books of the merged bank stopped being accepted after a notice period. Ask your branch for a new one.

Questions

What happens to an IFSC code when a bank merges?

The branches of the merged bank get new IFSC codes of the bank that took them over. The old codes keep working for a notice period, usually some months, and are then switched off. After that a payment to an old code is refused.

I sent money to an old IFSC code. Where is it?

If the code was already switched off, your bank refuses the payment or it comes back to your account, usually within a few working days. If it does not, give your bank the transaction reference and ask it to trace the payment.

What happens to IFSC codes when a bank's licence is cancelled?

The codes are taken out of the payment system and nothing replaces them. Depositors are covered by deposit insurance of DICGC up to ₹5 lakh for each depositor in each bank.

How do you know a code is old?

We keep the lists of bank branches published since December 2006 (the Reserve Bank's NEFT and RTGS lists and NPCI's lists, as compiled in the open razorpay/ifsc data set). A code that was in an earlier list and is not in the current one is shown as no longer in use.

Why is there no new code for some old branches?

After a merger many branches standing close to each other were joined into one, and a few were closed. We show a new code only when the bank's own rule gives it or when exactly one current branch has the same name in the same place. Otherwise we say so, because a wrong code is worse than none.
